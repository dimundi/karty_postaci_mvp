# Przepływ materiałów między Workshop a Portalem

1. W [[Workshop/kreator-szablonow]] przygotowujemy układ karty i definicje pól.
2. Kreator generuje HTML, PDF i konfigurację JSON z tych samych pozycji elementów.
3. PDF i konfigurację udostępniamy Portalowi. Szczegóły kopiowania plików opisuje dokumentacja kreatora.
4. [[Portal/edytor-kart-postaci]] wczytuje PDF i JSON. Użytkownik uzupełnia dane postaci i eksportuje kartę.

Dane postaci są oddzielone od układu karty. Powiązanie zapewniają stałe identyfikatory pól.

Talenty: [[Workshop/edytor-talentow]] i [[Portal/edytor-talentow]].

Podział aplikacji: [[start]]. Wspólne ustalenia: [[projekt]].
